Preprocessing Steps

Step 1 — Load Dataset: The loan approval dataset is loaded using Pandas.
Step 2 — Remove Duplicate Records: Duplicate rows are removed to improve the quality of the dataset.
Step 3 — Remove ID Columns: Loan ID and Customer ID are removed because they are identifiers and are not useful for prediction.
Step 4 — Encode Categorical Data: Categorical columns are converted into numerical values using Label Encoding.
Step 5 — Separate Features and Target: The input features are separated from the Loan_Approved target variable.
Step 6 — Train-Test Split: The dataset is divided into 80% training data and 20% testing data.

Machine Learning Preparation

After preprocessing, the cleaned numerical dataset is used for training classification algorithms.

The project uses Logistic Regression, Decision Tree, Random Forest, and K-Nearest Neighbors (KNN) for loan approval classification.
